# Telegram Lead & CRM Bot 🤖📊

Асинхронный Telegram-бот для сбора лидов, обработки заявок и управления продажами с встроенной админ-панелью и экспортом данных в Excel.

## 🌟 Основные возможности

- 📋 **Сбор заявок**: Пошаговый сбор данных клиента (выбор услуги, имя, валидация телефона, описание задачи).
- 👨‍💼 **Админ-панель (CRM)**:
  - Уведомления администратору о новых заявках.
  - Изменение статусов заявок (`Новая`, `В работе`, `Завершена`, `Отказ`).
  - Быстрый переход в WhatsApp с клиентом в один клик.
  - Фильтрация заявок по статусам.
- 📊 **Экспорт данных**: Выгрузка всей базы заявок в Excel (`/export`).
- ☁️ **Готов к деплою**: Встроенный Flask HTTP-сервер для прохождения Health Check на хостингах.

## 🛠 Технологический стек

- **Python 3.10+**
- **python-telegram-bot** (Async API)
- **SQLite** (база данных)
- **openpyxl** (генерация Excel)
- **Flask** (веб-сервер)
- **python-dotenv**
